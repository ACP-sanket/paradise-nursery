# Paradise Nursery 🌿

## React Shopping Application

Paradise Nursery is a React-based e-commerce application designed to provide users with an interactive online shopping experience for indoor plants.

## Features

* Landing page introducing Paradise Nursery.
* About Us section describing the company.
* Plant catalog containing 18 unique plants across 3 categories.
* Product images, descriptions and prices.
* Add to Cart functionality.
* Dynamic shopping cart item counter.
* Increase and decrease product quantities.
* Remove individual products from the cart.
* Automatic calculation of item totals and overall cart amount.
* Checkout button with a Coming Soon notification.
* Continue Shopping navigation.

## Plant Categories

1. Air Purifying Plants
2. Low Maintenance Plants
3. Succulents & Cacti

## Technologies Used

* React.js
* JavaScript
* Redux Toolkit
* React Redux
* React Router DOM
* HTML5
* CSS3
* Vite

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/ACP-sanket/paradise-nursery.git
```

Navigate to the project directory:

```bash
cd paradise-nursery
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
